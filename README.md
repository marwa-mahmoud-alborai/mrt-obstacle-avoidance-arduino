# 🚗 MRT Task - Arduino Obstacle Avoidance & Zone Tracking Simulation

An embedded systems simulation built on Wokwi featuring an Arduino Uno, HC-SR04 Ultrasonic Distance Sensor, Servo Motor for steering, LED indicators, and a Moving Average Filtering algorithm for smooth sensor readings.

---

## 🛠️ Hardware Components
* **Microcontroller:** Arduino Uno
* **Distance Sensor:** HC-SR04 Ultrasonic Sensor
* **Actuator:** Servo Motor (Steering Control)
* **Indicators:** Green LED & Red LED
* **Filtering:** Moving Average Filter (`NUM_READINGS = 5`)

---

## 📋 Features & Logic
* **Noise Reduction:** Uses a moving average algorithm to smooth out ultrasonic distance noise.
* **Zone Tracking:** Monitors obstacle distance continuously and changes LED indicators and steering angle based on proximity zones.
* **Wokwi Simulation:** Fully interactive circuit simulation link included.
